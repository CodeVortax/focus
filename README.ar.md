## ما هو فوكس؟

فكرة فوكس واحدة: **أنجز عملك أولًا، ثم أنفق ما كسبته.**

تقسّم يومك إلى مواد لكل منها قائمة مهام ومؤقت سخي. لكل مادة مكافأة، وإنجاز المهام يملأ **رصيد المكافآت** اليومي بالدقائق. تصرف هذه الدقائق عند **البوابة** أمام التطبيقات المشتِّتة، أو على مقاطع شورتس/ريلز، أو في المشغّل المدمج. وحين ينفد الرصيد تعرض عليك البوابة تصاريح مجانية قصيرة خلف عدّاد، أو تتيح لك المغادرة.

كل شيء يعمل على هاتفك. لا حساب ولا خادم، ولا صلاحية إنترنت في ملف المانيفست.

## المزايا

### الدراسة والمكافآت

- **المواد والمهام:** قوائم مهام لكل مادة، ومؤقت قابل للإيقاف المؤقت والتمديد، ومنبّه بصوت، وتذكيرات منطوقة عند تجاوز الوقت. اضغط مطولًا على البطاقة لتعديلها أو حذفها أو تغيير وسائطها.
- **رصيد المكافآت:** مكافأة كل مادة موزعة على مهامها وتُصرف عند إنجازها، ويُصفَّر الرصيد يوميًا. انظر [رصيد المكافآت](docs/architecture/treat-bank.md).
- **مهام الأسبوع:** أنجزها في أي يوم؛ كلما أسرعت زاد المضاعِف (من ×2 إلى ×1، ثم ×0.5 بعد التأخر).
- **ركن الأفكار:** احفظ الفكرة المشتِّتة في الملاحظات دون أن تغادر المادة.
- **الأحداث والاجتماعات:** تذكيرات بثلاثة مستويات؛ وعالية الأهمية منها ترنّ حتى تردّ.

### التحكم بالهاتف

- **البوابة الناعمة:** تختار أي التطبيقات المتتبَّعة (يوتيوب وكروم ويوتيوب ميوزك وVLC وتيليجرام) تحصل على البوابة، وعند فتح أحدها تظهر شاشة «لأي غرض؟» مع عدّاد قصير وخيارات تصاريح. انظر [البوابة والمراقب](docs/architecture/gate-and-watcher.md).
- **الفترات المقفلة («غير متاح»):** نوافذ زمنية لا يعمل فيها إلا التطبيقات المسموحة. والوضع الصارم يلغي زر الطوارئ.
- **عدّ شورتس/ريلز:** يكتشف شورتس يوتيوب وريلز إنستغرام وتيك توك، ويعدّ المقاطع، ويتيح لك المغادرة. انظر [اكتشاف شورتس](docs/architecture/shorts-detection.md).
- **وضع الشورتس الصارم (اختياري):** تفتح البوابة فوراً دون «أكمل هذا فقط»، والطريقة الوحيدة للمتابعة جملة تكتبها بيدك (اللصق ممنوع). ويمكنه تحويل الشاشة إلى الرمادي أثناء فتح الشورتس.
- **شاشة الاستخدام:** وقت الشاشة لكل التطبيقات على طريقة الرفاهية الرقمية: مخطط أسبوعي ودائرة وقائمة تطبيقات وشريط ساعات وسجل يومًا بيوم. انظر [شاشة الاستخدام](docs/guides/usage-screen.md).
- **مغادرة آمنة:** زر «مغادرة» يضغط رجوع للخروج من معظم التطبيقات، لكنه يرسل المتصفحات إلى الشاشة الرئيسية فيبقى سجل التبويبات.

### الملاحظات والقراءة والوسائط

- **ملاحظات** نصية وقوائم مهام، مع تنسيق غني (عناوين H1-H3 وعريض ومائل وتسطير وشطب وألوان)، وتصنيفات وتثبيت وأرشيف ومهملات وبحث ونسخ احتياطي وملاحظات صوتية. انظر [الملاحظات وPDF](docs/architecture/notes-and-pdf.md).
- **مكتبة PDF وقارئ** مدمج، أو فتح الملف في Episteme Reader إن كان مثبتًا.
- **مشغّل مدمج** لفيديوهات المكافآت، و**مشغّل موسيقى** بمجلدات وفنانين وقوائم تشغيل ومفضلة وطابور وتكرار A-B وسرعة/طبقة ومؤقت نوم ومعادل صوت.

### التحفيز

- سلاسل أيام ونقاط خبرة ومستويات.
- 42 وسامًا، منها 13 أوسمة مخفية في «قاعة العار». انظر [الأوسمة والخبرة](docs/guides/badges.md).
- 17 لعبة قصيرة للاستراحة. انظر [الألعاب](docs/guides/games.md).
- أربع أدوات للشاشة الرئيسية: **رصيد المكافآت** و**السلسلة** و**شورتس** و**اليوم** (بمربع لكل مادة). انظر [الأدوات](docs/guides/widgets.md).

### الملفات واللغات

- **ملفات `.foc` / `.fcs`:** حاوية واحدة تحدد ترويسةُ الملف نوعَه (فيديو/صوت أو PDF أو JSON لخطة اليوم أو الإعدادات أو الملاحظات أو حزمة لغة). انظر [صيغة ملفات foc](docs/architecture/foc-files.md).
- **خطّط بأي ذكاء اصطناعي:** شارك رده بصيغة JSON إلى فوكس مباشرة.
- **الإنجليزية والعربية** (من اليمين إلى اليسار بالكامل) مدمجتان، مع حزم لغات قابلة للاستيراد. انظر [اللغات](docs/architecture/i18n.md).

## كيف يعمل

```
WatchService (خدمة مقدّمة، تستطلع UsageStats كل ثانية)
  -> يعرف التطبيق الذي في المقدمة
  -> يسجّل الوقت لكل تطبيق ولموسيقى الخلفية
  -> التطبيق مراقَب؟    -> Overlay: «لأي غرض؟» + تصريح مجاني / صرف مكافأة / «أنا مشتّت» / مغادرة
  -> داخل فترة مقفلة؟   -> يمرّ المسموح فقط
FocusAccessibility (يوتيوب وإنستغرام وتيك توك فقط)
  -> ShortsDetector يقرر: هل هذه شاشة مقاطع قصيرة؟
  -> يُحتسب السحب (بعد استقرار الصفحة، بشرط أن يكون الفيديو قد تغيّر فعلاً)
شاشة الاستخدام -> SysUsage (أحداث استخدام النظام) إن سُمح، وإلا Db
الأدوات -> FocusWidgets.refresh() من حلقة المراقِب
Store + Db + NotesDb
  -> كل شيء محلي، ولا شيء يغادر الجهاز
```

التفاصيل الكاملة في [نظرة عامة على البنية](docs/architecture/overview.md).

## التثبيت

> فوكس حاليًا **نسخة تجريبية** (`0.16.0-beta`، رقم الإصدار 21). يتطلب **أندرويد 8.0 (API 26)** أو أحدث.

```bash
git clone <رابط-المستودع> focus
cd focus
# يلزم Android SDK، ويجب أن يحتوي local.properties على sdk.dir
gradle assembleDebug
# ملف APK: app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

المتطلبات: JDK 17 وAndroid SDK منصة 34 وGradle 8.7. ملاحظات Termux وCI في [دليل البناء](docs/guides/building.md).

**أول تشغيل:** يرشدك فوكس في الشاشة الرئيسية («مطلوب إعداد») إلى ثلاث صلاحيات: **الوصول إلى الاستخدام**، و**العرض فوق التطبيقات**، و**خدمة الوصول** لعدّ شورتس. ثم اضبط **البطارية > غير مقيّد** كي لا يقتل النظام المراقِب. التفاصيل في [دليل الإعداد](docs/guides/setup.md).

## الصلاحيات

| الصلاحية | لماذا يحتاجها فوكس |
|---|---|
| الوصول إلى الاستخدام | معرفة التطبيق في المقدمة وتسجيل الوقت لكل تطبيق ورسم شاشة الاستخدام. |
| العرض فوق التطبيقات | رسم شاشة البوابة فوق التطبيقات المراقَبة. |
| خدمة الوصول | ليوتيوب وإنستغرام وتيك توك فقط: اكتشاف شورتس/ريلز وعدّ السحبات وإغلاق التطبيق عند اختيار المغادرة. |
| مستمع الإشعارات | فقط لقراءة جلسات الوسائط النشطة وتسجيل موسيقى الخلفية. |
| الإشعارات والخدمة المقدّمة والإقلاع وقفل الاستيقاظ | تشغيل المراقِب والمؤقتات والتذكيرات بثبات. |
| الميكروفون | للملاحظات الصوتية، ولا يعمل إلا حين تضغط تسجيل. |
| قراءة الصوت/التخزين | مشغّل الموسيقى. |
| إنهاء العمليات الخلفية | إغلاق ما تبقى عند اختيار المغادرة. |

**لا توجد صلاحية إنترنت.** شرح كل صلاحية في [الصلاحيات](docs/guides/permissions.md) و[سياسة الخصوصية](PRIVACY.ar.md).
