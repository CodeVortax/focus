# Study launcher

A small, optional home screen: the time, the running subject timer, what is left on your plate, and only the apps you choose.

## Set it up
1. Home menu → **Study launcher** → **Choose apps**. These apps show on the launcher and are the only ones that work during a study lock.
2. **Home app settings** opens the phone's own page where you can make Focus Launcher your home app. Switch back any time in the same place.
3. Or just tap **Open it now** when you study.

## Study lock
- Start a lock from the launcher (**Study lock**: 25, 45, 60, 90 or 120 minutes) or from the launcher settings.
- During a lock every other app is blocked by the strict block screen (no emergency button), and the phone's settings can't be opened, so the lock can't be switched off from there.
- It ends by itself. To end a time lock early, type the sentence the launcher asks for.
- **Lock while a subject timer runs** is a second mode: the lock lasts as long as a timer is running. Pause or stop the timer to get out.

The lock needs usage access, overlay and accessibility (Settings → Permissions), like the gate. It is a speed bump you set for yourself, not a security feature: someone who reboots into safe mode or uninstalls Focus can get around it.
