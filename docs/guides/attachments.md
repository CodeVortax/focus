# Notes attachments

Tap **+** at the bottom left of a note.

| Choice | What it adds |
| --- | --- |
| Photos and videos | thumbnails you can tap to open |
| Attach file | any file: PDF, music, documents |
| Record audio | a recording with the mini player |
| Add a link | a web address with an optional title |
| Link a note | a tap-to-open link to another note |

Picked files are not copied; the note keeps a link to them. Removing an attachment never deletes your original file (recordings made in Focus are deleted).

## Arrange
The button at the bottom right toggles **Arrange**. Drag the handle to move a checklist item or an attachment; the list changes when you let go. Tap the check to finish.

## Recording
Voice is saved as Opus (AAC on Android 9 and older). Settings > Notes, PDF and recordings picks Smallest (24 kbps), Balanced (32) or Best (64). A new recording has a temporary name; Focus asks for a real one when you stop (you can skip, or turn the question off). Type the name only: **Save a copy...** adds the right extension.
