# Games

Seventeen short games for a break between tasks. Everything is drawn in code on a Compose canvas: no images, sounds or other assets. Best scores are stored locally. The ideas and rules of Snake, Brick Breaker, Flappy Bird, Dino Run, Yahtzee and Space Invasion come from [formulas-games](https://github.com/GuillaumeFalourd/formulas-games) (Apache-2.0) and were rewritten from scratch for touch screens. See [third-party notices](../../THIRD_PARTY_NOTICES.md).

| Game | Idea |
|---|---|
| Blocks | Falling blocks, find the rhythm |
| Beat Dash | Hold to jump in time with the beat |
| Snake | Eat, grow, avoid walls and yourself |
| Brick Breaker | Smash every brick; colours give power-ups |
| Flappy Bird | Hold to rise, release to sink |
| Sky Flap | Tap to flap through the gaps |
| Dino Run | Jump cactus, duck birds |
| Space Invasion | Shoot the fleet before it reaches you |
| Stack Tower | Tap to drop blocks, precision wins |
| Sudoku | Three difficulty levels, best time per level |
| 2048 | Slide and merge tiles |
| Minesweeper | Clear the field, best time |
| Yahtzee | Five dice, three tries a turn |
| Memory Match | Find the pairs in the fewest moves |
| Schulte Table | Find 1 to 25 in order, an attention drill |
| N-Back | Working-memory workout |
| Reaction Test | Tap the instant the screen turns green |

The last four are brain training rather than arcade games. Source: `ui/*Game.kt`, `ui/BrainGames.kt`, `ui/GamesScreen.kt`.
