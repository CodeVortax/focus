# Languages and RTL

Focus ships **English** (the source strings), **Arabic** (with full right-to-left layout), **Russian**, **German** and **French**, and accepts any number of extra languages as imported packs.

## How strings work

Every user-facing string in code is written in English and wrapped in `tr("...")`, or `trf("...", args)` for formatted ones. At runtime `tr` looks the English text up in the active table and falls back to the English text itself, so a missing translation is never blank.

```kotlin
Text(tr("Treat bank"))
Text(trf("Bank: %s min", minText(bankSec)))
```

`I18n.version` is Compose snapshot state, so the whole UI recomposes the moment the language changes. `I18n.rtl` drives layout direction. Text-to-speech uses `Locale(code)` for the spoken timer messages.

## Built-in tables

| Code | Source |
|---|---|
| `en` | Empty table, keys are the strings |
| `ar` | `data/Strings.kt` (`AR`) and `data/StringsExtra.kt` (`AR_EXTRA`), `rtl = true` |
| `ru`, `de`, `fr` | `app/src/main/assets/lang/<code>.json`, the same format as an imported pack, loaded by `I18n.apply` |

On a fresh install the language follows the phone's language when it is one of these. To fix or improve a built-in translation, edit its JSON file; keys are the exact English strings used in `tr(...)`.

## Language packs

A pack is a JSON file of kind `lang`:

```json
{
  "focus": "lang", "v": 1,
  "code": "fr", "name": "Francais", "rtl": false,
  "strings": {
    "Treat bank": "Cagnotte",
    "Setup": "Reglages"
  }
}
```

| Key | Meaning |
|---|---|
| `code` | Short code, lower-cased on import; also used for text-to-speech |
| `name` | Name shown in the language picker |
| `rtl` | `true` for right-to-left languages |
| `strings` | Map from the English string to its translation |

Importing saves the pack in `Store` and selects it. Packs appear in **Setup > Language** next to the built-in languages.

## Translate with any AI

1. **Import / Export > Language template** produces a pack containing every UI string.
2. Give it to an AI and ask for the `strings` values to be translated, keeping keys, `%s`/`%d` placeholders and the JSON shape.
3. Set `code`, `name` and `rtl`.
4. Import the result as a `.foc` file or pasted text.

Placeholders must survive translation unchanged, or formatted strings will break.
